# VIS-standing-crowds（路边站着、走着的人）

- 墙边家具和路边的人对不上时，改家具，不按人群改 kit：通用 chunk 是池化模板（同一个模板用在别的里程），kit 读 `ctx.seg.npcGroups` 判断「这里有人」是错的。把储物柜嵌进墙（只探出 5 cm）、窗台和暖气片收到 |x| ≥ 1.72，与人的位置无关，一条「墙边 0.1–1.9 m 高的静态顶点 |x| ≥ 1.72」的 kit 测试就能锁住。
- 人的横向尺寸：上身连手臂宽 0.555（臂中心 ±0.24，臂宽 0.075），躯干深 0.22，班长抱的本子宽 0.46。走廊路边带 [1.54, 1.6] 离墙只有 0.2 m：侧身（yaw 0 / π）的人手臂必然进墙，站着的人要面朝走廊（偏差 ≤ 0.45 rad），侧身走的人贴内沿 1.54。
- 楼梯右侧栏杆在 x = 1.5，没有合法的路边（要 ≤ 1.30 才不跨栏杆，又会伸进右道碰撞盒 1.32）：楼梯段的组一律放左墙，数据里写 `side: 'L'`，和画出来的一致。
- 楼梯的画面高度：编译段 floorY 是连续坡线（碰撞、Sim 用），kit 画的是平踏面（拍 k 覆盖 [k − 0.5, k + 0.5]）。画面上站在楼梯上的东西用 `render/stairTread.ts` 的 `treadY`，kit 用同一个 `treadS` 取整，kit 测试按踏面三角形逐个比对。hitbox 照旧用 floorY。
- 走路不滑脚：支撑期让 sin(髋角) 随距离线性变化（2 × 腿长 × sin 22° ≈ 步长 0.62，正好抵掉身体前移），摆动期余弦缓入缓出；bob = max(两腿竖直伸展) − 腿长。正向运动学按 LegForest：大腿转 −hip，小腿再转 +knee，竖直伸展 = thigh·cos h + shin·cos(k − h)。腿长常量放在 behaviors.ts（不依赖 three），LegForest 的 BODY 引用它，两边不会漂。
- 两条腿不再满足 hipL = −hipR（支撑期不是正弦），真正的不变量是「右腿 = 左腿走过一步长之后的姿势」，测试按这个写。
- 展开时的拒绝采样（围观的弧）：先把这一个人的随机数全部取完再判断要不要 push，跳过一个人不会让后面的人换位置；`lookFor` 的键用 `out.length`，剩下的人衣服颜色会变，属正常。
- 人群段的完整着色按段、不按姿势：footOut 的上身是烘进原型几何体的（`SOFT_UPPER` 写在 aHw.y），不能靠实例参数切换，要另建一个变体（`seatedFull`），由 `PlaceCtx.wall` 选。
