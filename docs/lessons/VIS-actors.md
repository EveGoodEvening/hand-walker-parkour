# 视觉修复 · actors（主角、替身、第三只手、静场姿势）

- 楼梯：模拟的 `floorY` 是连续坡线，台阶却是一级一级的平踏面（拍 k 的踏面覆盖 [k − 0.5, k + 0.5] 拍，高 = 坡线在 k 处）。踏面公式只写一处（`levels/compile.ts` 的 `stairStepCentre` / `stepFloorY`），kit 和主角都调它。渲染端的地面形状经 `CrawlInput.ground`（`GroundProfile` 对象，复用同一个实例，不建闭包）传进去；没有楼梯的段传 null，平地姿势不变。碰撞和求解器不动。
- 楼梯上手要按在「落掌处那一级」上，不能用身体所在的坡线高度，否则锁定的手每个支撑期上下滑一级（15 cm）。光改手不够：平地上手臂已经几乎伸直（肩高 0.43、手在肩前 0.38），下楼时够不到下面那一级。身体要绕髋与肩之间的点（离地 0.4 m）顺坡俯仰，手在肩前的距离也按坡度转（`reachOnSlope`：下楼近、上楼远）。行李腿随根一起转，就不会戳进上面的台阶或悬在下面的台阶上。
- 摆动的手在楼梯上会切过台阶的前沿（下楼）或撞上踢面（上楼）：弧线再抬高约半个落差；上楼时摆动的前 18% 先原地抬手再往前送。验收用蒙皮后的全部顶点对照「各自里程处的踏面高度」，比只查关节可靠（指尖是最先穿进去的）。
- 静场里要连 actor cue 也不画主角：`SET_DEFAULT_CLIP` 的变体键显式写 null（`'bedroom.feet': null`）。查表不能用 `??` 串变体键和 set 键，null 会落到 set 键的缺省姿势上；cue 生效时 Actor 又会改用 cue 的姿势。被子的高度场已经表现了腿、膝盖拱起和「终于放松」，画出来的腿只会变成穿着鞋躺在被子上面。
- 替身被转过来面朝镜头之后，原来「手搭在桌上」的坐姿会变成双手伸向镜头。改替身的朝向时，把姿势里所有指向原来那张桌子、那面墙的目标一起检查一遍。
- 第三只手的 shush：头骨关节在颈顶，头球心在它上方 0.095 m、眼在 0.1 m，嘴约在 +0.045、前 0.12。手指朝上、略向后点在唇上，手侧过来（掌心朝身体中线），从正面看是一根细条。手指是一整块刚性蒙皮，不能单独弯，所以只能靠「侧着」让手变窄。肘给一个横向的极向量，前臂从脸颊外侧上来，不从胸口正中穿过下巴。
- 记忆闪回的人在窗洞里：缩放要以手腕为中心（不是根：handstand 的根在手腕上方 lift − 0.03 处），手腕放在窗台上方 8 cm，比例按窗洞高度算。沿 s 放在追尾镜头前方 0.4 × 半个水平视角，比侧墙替身（0.75）远：贴墙站的人挡不住视线（0.5 时 1-2 @48 左墙的人正好挡住它，Node 里按人的位置算视线可以先查出来），替身也离开画面左缘。竖屏水平视角只有约 44°，窗洞本身就在左缘，验收线要分开写。
- 机位用 Node 网格搜索（场景台 `scene(def, tier, aspect)` 现在可以指定宽高比）：小腿和鞋的全部顶点在画面里的比例、投影包围框面积、视线仰角、画面里的 NPC（`expandSegment` 算出人的位置）一起打分，横屏、竖屏分开选。只查两个踝关节会放过「鞋在画面外、巨大」。
