# WP5 Lessons

只追加（OWNERS.json APPEND）。记录可复用的经验：库版本、踩过的坑、被纠正的做法。lead 集成时汇总到 AGENTS.md。


- 姿态构建（`actors/handCycle.ts` 的 PoseBuilder）按拓扑序写局部旋转、同时维护 FK。改了父骨骼之后，子骨骼缓存的关节位置是旧的：做两骨 IK 之前必须先对上段骨骼 `fk()` 一次，否则 IK 从静止姿势的肩膀出发，手永远够不到目标（踩过：手腕停在目标前 9 cm、低 4 cm）。
- 无头测试的时间：`__game.step(n)` 之后只渲染一帧，按渲染 dt 推进的过渡（dt 还被截到 0.1 s）几乎不动，「上一帧的相机位置」也可能是很久以前的。WP5 的过渡、淡入淡出、计时一律按模拟时钟差推进（不截断）；弹簧类在间隔 > 0.25 s 时直接吸附；依赖相机的放置（侧墙镜替身沿 s 放在哪）用 §5.4 追尾机位的解析值，不读上一帧的相机。截图清单里在截图前加 `(()=>{for(let i=0;i<24;i++)__game.step(2,{render:true})})()`，模拟真实帧率下的最后 0.4 s。
- PoseHistory 按 tick 需要数据，但姿势只在渲染时算：两次渲染之间隔了多个 tick 时，主角按首尾快照线性插出中间各 tick 的爬行输入补写历史（纯函数 crawlPose，不动弹簧状态），否则 0.35 s 延迟的替身在无头测试里采到的是一帧很旧的姿势。
- 侧墙镜的「真实」倒影在玩家同一里程处，离追尾镜头的视线约 66°，根本看不见。替身不做真实反射：按墙面对称放进镜中房间，离玻璃的深度按玩家到墙的距离压缩（0.4–3.2 m），沿 s 放到镜头前方约 0.6 × 水平半视角处（三条车道都看得见，单元测试 + 截图）。端墙镜替身离玻璃 0.2 × 玩家到镜面的距离，横向压缩一半，保证在 1.9 m 宽的开口里。
- 脚本姿势（clip）自带根高度（站立 0.5 m、倒立 0.69 m）。放置替身时要把地面高度加上去，不能覆盖 root.y，否则站着的替身陷进地里一半。
- 平面影子：光线太陡（morning 的 planarDir 仰角约 58°）时爬姿只有 0.3–0.6 m 高的身体把影子全压在身下，追尾镜头看不见。投影前保证光线水平分量 ≥ 1.2 × 竖直分量（方向不变），影子才「永远落在前右方」。影子材质用 FrontSide：压扁的闭合网格朝上的面投下来是正面、朝下的面被剔除，没有模板时也只压暗一层；用 DoubleSide 时降级路径处处压暗两次。
- 像素检查（`__game.ext.wp5PixelCheck`）：渲染到带 stencilBuffer 的 WebGLRenderTarget，在同一个任务里 readRenderTargetPixels；渲染目标是线性色（没有色调映射）。测遮罩范围时要把透明叠加层也藏掉，否则叠加层混在标记色上，标记色被冲淡、数不出来。
- 在 WP3 的 LampField 补丁之上再改 Lambert 着色器（替身去饱和）要串联 onBeforeCompile，并串联 customProgramCacheKey（`${prev()}|wp5tint`），不能直接覆盖。
- CORE 占位 kit 的端墙镜「镜框」是一整块实心面，把开口挡住了（已写进 contract-requests/WP5.md）；1-6 的替身和「嘘」在占位世界里只能从镜中房间内部看（截图清单里有 inside 一张）。WP3 的走廊 kit 只要按 §5.8 留洞就没问题。
- 检查点在段中间时，重来不会重放检查点之前的段内事件：在检查点之前出现的替身（double cue）重来后就没了。写数据时替身的 double cue 放在检查点之后，或者在检查点之后再发一次。
- 静场里主角由 WP5 画：放在 `STILL_ORIGIN × StillSet.playerAnchor(variant)`，锚点约定为「主角骨盆正下方的地面，主角朝 −z」；各 set 不要自己画主角的身体（CORE 的占位 set 画了两只静态的鞋，会和主角重叠）。机位（shots.ts）也相对这个锚点。
- 调试扩展里读当前里程用 `__game.getState()`：`step(n)` 之后还没渲染时，ViewSystem 最后收到的快照是旧的。
- 单元测试：Float32 存的四元数 slerp 后用 `angleTo` 比较，acos 在 1 附近放大误差，约 5e-4 rad，阈值取 1e-3。
- 摔倒机位按 §5.4 的 (0.2, 0.18, +1.0) 会插进拖在身后的腿里（腿拖到根后方约 1.1 m，右脚正好在那儿），画面被一条裤腿占满。实现里横向让到腿外侧（x + 0.6），高度、距离、滚转照旧。
