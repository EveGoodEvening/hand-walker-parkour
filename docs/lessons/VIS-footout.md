# VIS-footout：伸进过道的脚（坐姿、无主的椅子、陈默的腿）

- 先查骨架，再看贴图：人物姿势写成「髋、膝、踝」三个点时，单元测试要量骨长（和 `LegForest.BODY` 比，±5%）和膝盖相对髋—踝连线的位置（不能在连线下方，即不反折）。以前 footOut 为了满足「车道上方不高于碰撞上沿 + 5 cm」，把膝盖压到离地 0.14 m，腿反折约 40°；没有上身时看不出来，补上上身轮廓后就成了「坐着的人腿瘫在地上被拖着」。
- 从 0.44 m 的椅面伸直的腿，车道中心约 0.27 m 高、车道近端约 0.45 m：这是几何事实，碰撞盒（0.16 m）不能改时，只能放宽「顶边」规则的取样范围（只看车道远端的脚踝和鞋），同时用骨架测试守住形状。规则本身编码了错误画面时，改规则要在测试注释里写清原因。low 一律撑跃，斜着的小腿不改变玩家要做的动作。
- 同一个原型按场景换姿势：`PlaceCtx.kit` 已经带着场景，走廊（`corridor`）里的人坐在地上、不带椅子，教室和食堂坐椅子。新变体放进同一个 InstancedMesh；变体顺序按「同一场景一起用」排，drawRange 才连续。
- 收腿时不要整个人绕髋转：外沿 ≤ 0.86 m 的约束对每一个伸缩进度都要成立。腿单独一个变体绕髋转，上身另一个变体只扭 0.3–0.4 rad 并坐直（后仰随伸出程度变）。测试直接用导出的 `footBodyMatrix` / `footLegMatrix` 扫 e ∈ [0, 1]，和 `place()` 共用同一份矩阵代码。
- `GeoBuilder.segment` 用最短旋转对齐，斜放的长方体截面会绕长轴歪，顶面的粉笔条随之倾斜。需要「高」始终朝上时自己 `makeBasis`（`footOut.ts` 的 `limb`）。
- 陈默留在过道里的腿：`LegForest` 的目标腿是一根按髋—踝距离缩放的直腿（上限 1.25），目标点离髋太远就是僵直的侧踢。脚踝放在碰撞盒里靠他的一侧，等他让到 65% 再伸出去，髋降 2.5 cm、支撑腿微屈（`cos(hip) = (STAND_HIP − drop − ankle) / 腿长`，脚仍着地）。`boundary.test` 要求让开后髋高 > STAND_HIP − 0.05，降幅不能超过 5 cm。
- 在单元测试里按帧量人的位置时，要排除越过之后缩小消失（U6 的 `applyFade`）的那几帧：矩阵的 `getMaxScaleOnAxis() < 1`。
