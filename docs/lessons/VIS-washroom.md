# VIS-washroom 教训（视觉审查 school-sets-5/6/7，2026-10-17）

- 墙镜开口很低（0.25 m 起）时，洞前的东西（洗手盆的龙头、下水管）后面没有墙，会像悬在暗处的棒棒糖。办法不是挪开口，而是在 kit 的同一个几何体里按镜面 x' = −2·HW − x 画一份倒影：倒影只画朝镜外的面（+x、上下、两侧），倒影的 +x 面就是实物贴着镜子的那一面。实物朝镜子的 −x 面永远看不见，不用画。单元测试：洞前每个顶点都要在镜像位置找到对应顶点（`kits.test.ts`「厕所镜」）。
- 替身被前景挡住，先想「镜头在主角身后 2.35 m，倒影在主角身边」：挡它的只会是这段里程上的东西。kit 可以读 `ctx.seg.events`（`at` 是拍，`s = segS0 + at × stride`），在关键事件前 3 拍到后 12 拍内不放遮挡物，比调替身深度可靠。
- 镜中房间的颜色要由反光面的 `backdrop` 决定（kit 层 `mirrorRoomsRaw` 与 WP5 `BACKDROPS` 都读它），不要由 kit 传参：两层只有这样才不会各调各的。WP5 的房间比 kit 的房间内缩，镜子活动时只看得见 WP5 那层，以及放在房间体积里的 kit 几何体（灯管倒影、盆的倒影）。
- 「暗色镜中房间」不等于近黑：在亮的白瓷砖房间里，近黑的长条读成水族箱或没开灯的窗。约为真实墙面一半亮度、画出对面隔间与地砖缝，就读得出是镜子，替身（浅色上衣、深色裤子）照样清楚。
- 改贴图集里某一块的随机数次数会打乱后面所有区域（贴图集共用一个 `rng`）。新的画法用单独的 `texRng('<名字>')`，原来的 `rng` 照旧消耗同样次数。
- 墙裙鞋踢痕：用 `lineCap: 'round'` 的细线（长度 ≥ 4 倍粗细）加一笔更宽更淡的晕边，比实心椭圆像擦痕；太淡（不透明度 < 0.2）在 2–4 m 外就看不见了，0.18–0.38 合适。
